契约先于写作：每一类页面需要哪些字段、允许什么审稿级别、哪些写法禁用。

模板字段

{
  "work": {
    "required": [
      "id",
      "title",
      "creator",
      "year",
      "image",
      "source",
      "license",
      "note"
    ],
    "deep_read_required": [
      "why",

      "relation",
      "sources"
    ]
  },
  "theme": {
    "required": [
      "key",

    "b_extra": [

      "works",

  },

      "slug",

禁用写法

  • 把 AI 预审写成人工/专家审稿
  • 无来源的因果断言
  • 用生成图冒充历史照片
  • 把推测写成馆藏结论
