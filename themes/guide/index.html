维护口径Maintenance rules

这些规则决定后续内容怎么加，不是一次性文案。These rules govern how content is added later; they are not one-off copy.

RULE

主题页不重复写史；史在绘画史/摄影史。Theme pages do not repeat history; history lives in the two history sites.

RULE

A/B 主题必须有两边选件；C 主题不硬做并置。A/B themes need both sides; C themes do not fake a pairing.

RULE

旧主题 URL 用 meta refresh，不声称 301。Old theme URLs use meta refresh; we do not claim a 301.

RULE

今日一画/一影是编辑排期，不是创作日期。Today's painting/photo are editorial selections, not creation dates.

RULE

每件作品保留来源、作者、授权与对象页。Every work keeps source, creator, rights and object page.

RULE

新增作品先入数据，再进主题页。New works enter data first, then theme pages.
