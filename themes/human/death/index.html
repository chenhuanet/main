死亡与记忆Death and Memory

墓葬、墓碑、葬礼、灾难与纪念。死亡不是终点，而是一组需要被安排、被观看、被重复的仪式。Tombs, graves, funerals, disasters and memorials. Death is not an endpoint but a set of rites to be arranged, watched and repeated.
